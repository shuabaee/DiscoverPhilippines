# Peer Review Report

**Reviewer:** Tagalog, Prince Darens | @minju0-0  
**Repository Reviewed:** DiscoverPhilippines  
**Date of Review:** October 2, 2026  

## Project Structure Rating: 10 / 10
 
The project is neatly organized, with separate folders for the pages, the layout, the data, and the services. I especially appreciate that the reviews feature is handled in its own dedicated part instead of being mixed in with the page design, which keeps the project clean and easy to understand. The commit messages follow the conventional commits format, using labels such as "feat", "refactor", and "chore" at the start of each entry, which keeps them clear and consistent. Each message states exactly what was done, for example "feat: add destination search and filtering" or "refactor: migrate custom css to tailwind". Reading through the history shows the full progression of the project, from setting up the styling, to adding search, then the popups, and finally the reviews page. The page names (Home, Destinations, Cultures, Reviews) also match the site's menu, which makes the project easy to navigate.
 
---
 
## Front-End Rating: 10 / 10
 
This is an attractive and well-executed site. The home page opens with a full-screen photo, a gold "Pearl of the Orient Seas" badge, a strong headline, and a button that lifts slightly on hover, making a great first impression. The ocean blue and gold palette and the choice of fonts remain consistent on every page, so the site feels like one cohesive experience. It also offers a solid set of working features: search that updates as you type, a location filter, clickable destination cards that open a popup with the best time to visit, trip length, and activities, culture popups with images, and a reviews page where visitors can choose a destination, give a star rating, leave a comment, and filter what others have written. A "No reviews yet" message appears when there is nothing to show, which is a thoughtful touch. The layout adapts well to different screen sizes, with destination cards shifting from one column to three. Overall, the site feels complete, and the flow from browsing destinations to leaving a review is logical and easy to follow.
